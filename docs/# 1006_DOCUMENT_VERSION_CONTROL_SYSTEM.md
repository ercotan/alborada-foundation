# SISTEMA OFICIAL DE CONTROL DE VERSIONES DOCUMENTALES DE LA FUNDACIÓN ALBORADA
## Fundación Alborada

Versión 1.0

Clasificación: Norma Institucional de Gestión Documental

---

# PROPÓSITO

El presente documento establece el sistema oficial de control de versiones para toda la documentación de la Fundación Alborada.

Su finalidad es garantizar que cada modificación realizada sobre cualquier documento pueda ser identificada, comprendida, auditada, recuperada y preservada, asegurando la integridad del conocimiento institucional durante toda la existencia de la Fundación.

Ningún documento podrá modificarse sin generar una nueva versión registrada oficialmente.

---

• Bases de conocimiento.

• Documentación técnica.

• Documentación generada por HERA.

# FILOSOFÍA

La evolución del conocimiento debe quedar registrada.

Eliminar el pasado significa perder inteligencia.

Cada versión representa una etapa del crecimiento institucional.

La Fundación nunca perderá la capacidad de reconstruir cualquier decisión tomada.

# CONCEPTO DE VERSIÓN

Se considera versión toda modificación aprobada oficialmente sobre un documento.

No importa la magnitud del cambio.

Toda modificación genera una nueva versión.

---

# ESTRUCTURA DE VERSIONADO

La Fundación utilizará el siguiente estándar.

```
MAJOR.MINOR
```

Ejemplos.

1.0

1.1

1.2

2.0

3.0

---

# CAMBIOS MAYORES (MAJOR)

Se incrementará el primer número cuando existan modificaciones que alteren significativamente el contenido.

Ejemplos.

Cambio de estructura.

Cambio de políticas.

Cambio doctrinal.

Cambio de procedimientos.

Cambio de responsabilidades.

Cambio de alcance.

Ejemplo.

1.4

↓

2.0

---

# CAMBIOS MENORES (MINOR)

Se incrementará el segundo número cuando existan.

Correcciones.

Mejoras.

Aclaraciones.

Actualización de ejemplos.

Optimización de redacción.

Actualización de referencias.

Ejemplo.

2.0

↓

2.1

↓

2.2

---

# CAMBIOS EDITORIALES

Errores tipográficos.

Ortografía.

Formato.

Diagramación.

No modificarán la versión principal.

Se registrarán únicamente en el historial.

---

# HISTORIAL DE VERSIONES

Todo documento deberá incluir una tabla de historial.

Ejemplo.

|1.1|2026-08-10|Gestión Documental|Correcciones menores|Consejo|
|2.0|2027-01-15|Dirección|Reestructuración completa|Consejo|

Toda versión tendrá un estado.

SUSPENDIDA.

OBSOLETA.

---

# VERSIÓN VIGENTE

Solo podrá existir una versión vigente de cada documento.

Las versiones anteriores permanecerán archivadas.

Nunca serán eliminadas.

---

# VERSIONES OBSOLETAS

Las versiones obsoletas.

No podrán utilizarse para operación.

Se conservarán únicamente por razones históricas y de auditoría.

---

# RECUPERACIÓN

Toda versión podrá recuperarse.

Nunca se sobrescribirá una versión anterior.

Toda recuperación generará una nueva versión vigente.

La Fundación Alborada establece que el conocimiento institucional evoluciona continuamente y que dicha evolución debe quedar documentada de manera íntegra, transparente y permanente.

El presente Sistema Oficial de Control de Versiones garantiza la preservación de la memoria institucional, la trazabilidad de todas las decisiones documentales y la continuidad operativa de la Fundación durante las generaciones futuras.
